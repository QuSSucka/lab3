# Лабораторная работа №3 по PHP

Учебный проект Самойлова А.В. (группа 25-ИСТ-3) по дисциплине «Программирование на языке PHP».

В репозитории:

- настройка Composer и автозагрузки классов по стандарту PSR-4 (пространство имён `App\` → папка `src/`);
- регистрация и авторизация пользователей с хранением данных в MySQL;
- пользовательские настройки (цвет фона и цвет шрифта), которые передаются в браузер через cookie;
- автоматический вход, если пользователь не вышел из аккаунта.

## Запуск

1. Выполнить `composer dump-autoload`.
2. Создать базу данных скриптом `schema.sql`.
3. Скопировать `config.example.php` в `config.php` и указать параметры подключения к MySQL.
4. Открыть проект в браузере: https://lab3.local
